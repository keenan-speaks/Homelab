# Security Policy

## Overview

HomeLab is a self-hosted infrastructure project. The repository is publicly available, however no production secrets or credentials are stored within git version control.

## Reporting Security Issues

If you discover a security issue within this repository, please do **not** publish sensitive details in a public issue.

Instead, describe the problem privately so it can be reviewed and resolved.

## Sensitive Information

The following items are intentionally excluded from this repository:

* Passwords
* API keys
* Private SSH keys
* VPN credentials
* Environment files (`.env`)
* Authentication tokens
* Backup archives
* Personal information

Example configuration files are provided where appropriate to demonstrate the setup without exposing production values.

## Responsible Disclosure

Security improvements are documented through normal commits and release notes whenever possible.
